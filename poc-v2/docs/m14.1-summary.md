## 1. Q1：snippet 插入包内失败

**现象**：点击 Palette 拖入 snippet 到一个 Package 内时，新插入的元素落到了包外（顶层），导致后续 `expose` / `select` 全部找不到。

**根因**：snippet 插入点算错 —— `findInsertPoint` 没有落在目标 package body 内，而是一律落到顶层 body 末尾。

**修复**（`da167a0`）：把插入点改为先定位到目标 package 节点内的 body 起点，再走 P0 引入的统一插入路径（AST offset 级）。

**回归护栏**：补单元测试覆盖「snippet → 包内」这条路径。

## 2. Q2：元素进树回归

**现象**：M14 元素进树改动后，画布新建的元素不在树上显示。

**根因**：tree 缓存 store 在 M14 中引入了 `owner_id` 字段，但画布新建时未触发对应 invalidate。

**修复**（`f721944`）：在画布创建元素的 success handler 中显式 `invalidate(ownerId)`，并补单测。

**截图**：截图 02（`02-auto-named-element-palette.png`）重拍，确认「无错误」状态。
